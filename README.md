# Gboard 中文本地增强

基于 Gboard 18.4.1 的非官方适配：保留原生键盘前端与英文解码器，用本地 Rime、雾凇词库、万象语法模型增强中文，通过独立 Sherpa-ONNX 服务提供普通话和英文混说的离线语音。

代码仓库公开，正式安装包位于 [最新 Release](https://github.com/LumiaBlack51/gboard-local-chinese/releases/latest)。APK 包含原 Gboard 闭源代码，新增源码不改变第三方代码及数据的许可。签名私钥不在仓库或 Release 中。

## 已实现

- 1.3.0 整理离线语音英文大小写；新增可关闭的中文、英文及混输校对。中文量化模型优先使用 Snapdragon 8 Elite 的 Hexagon NPU，英文使用 15.5M 参数的小模型。独立校对组件约 162 MiB，不联网，按需运行；可跳过并使用原文，修改后短暂显示恢复原文按钮。
- 输入完成后的右侧按钮可选“展开替换成叉”（默认）、“叉和展开都显示”、“只有展开”；组成拼音时仍保留原生展开。
- 语音句末自动补句号／常见问句问号，已有标点保留；目前不自动推断中文句中逗号。可关闭的“语音快速启动”在非隐私键盘显示时预载识别模型，不提前录音，键盘隐藏后解除绑定。校对最多等待 2.5 秒，超时直接使用识别原文。

- 1.2.6 修复手机把独立语音服务录音静音的问题：输入法采集麦克风，经内存管道交给离线识别服务，载入期间的声音也保留到识别结束。空结果和录音错误保留面板并提供重试。
- 手写修正起笔阈值前丢点、底排触摸修正污染笔迹坐标，以及长笔画尾部截断。管理应用新增“手写连写”开关（默认关闭）：逐笔渐淡，停笔约 0.9 秒自动选首候选，旧字未消失时可写下一字。识别保留完整笔画，淡出的旧字不混入新字。

- 1.2.5 本地构建修正输入法窗口内触摸坐标换算，解决上一版 C/V/B/N 被送到上排的回归；短候选按格宽限制字号，文字绘制限制在格内，避免窄格溢出。相关修复已包含在 1.2.6。
- 1.2.4 本地构建保留字母与空格交界判定；语音面板保留输入框焦点并使用当前输入连接，同一输入框刷新连接可继续填入，提交失败保留结果供重试。触摸坐标回归已由 1.2.5 修正。
- 1.2.3 本地构建将候选／联想文字默认放大 15%；管理应用中的“键盘文字大小”和“候选／联想文字大小”可独立加减、恢复默认，范围 80%～150%，自动保存。相关修复已包含在 1.2.6。
- 中文全拼、简拼、组合成句、词语补全、后续候选和本地选词学习；补全索引包含 874,429 条记录。
- 确认前左右滑动空格键移动拼音光标，每跨一个字符请求一次震动；松手不选词。点按拼音行会放大显示，选好位置后可继续用空格微调，再插入字母或退格。
- 中文 26 键点击仍输入拼音，拖动替换为离线手写笔画。逐字书写并选择候选，删除键撤销上一笔；首笔为点时稍按住约 0.22 秒。应用中可开启独立手写板，板上点“26键”返回。
- 保留原生英文预测、英文滑行输入和隐私键盘界面。普通按键继续走 Gboard 原有触控路径；新增拼音光标触感遵循安卓系统设置，可在管理应用关闭。
- 隐私或密码输入使用禁用用户词库的中文方案，不写选词学习，关闭麦克风。
- 点击麦克风立即录音，识别到一句话结束后自动填入并关闭语音面板，无需开始或结果确认；也可手动结束录音或取消。同一个双语模型处理普通话与英文混说，保留英文单词间空格，只处理内存音频。
- 输入未确认拼音时保留原生展开候选按钮，不显示 ×；文字提交后的联想栏按管理应用中的选择显示 × 或展开，点击 × 关闭联想、恢复工具栏。并列显示时两者独立占位。
- 扩展候选追加加载时保留当前选择，避免跳到最后一页；未确认拼音按回车只提交原始字母，再次回车才执行搜索或发送。
- 打开应用 → 检查更新 → 下载并安装。更新页面显示实际已安装的键盘、语音和更新器版本，区分服务器新版与安装完成；安装后核验全部 APK。相同版本也可“重新安装此版本”修复，校验通过的缓存可复用。

键盘和语音服务均没有 `android.permission.INTERNET`，关闭系统备份。更新应用具有联网和安装权限，独立 UID，没有麦克风、键盘或输入内容读取接口。语音服务对调用方核验签名。没有读取讯飞学习数据库，没有调用讯飞代码或服务。

## 安装

首次安装下载最新 Release 的七个 APK：`base.apk`、三个 `split_*.apk`、`voice-helper.apk`、`updater.apk`、`proofread.apk`。键盘 split 必须一起安装；ARM64、Android 12L 或更高。`proofread.apk` 是可选的中英校对组件，不安装仍可录音、识别并整理英文大小写。首次安装校对组件后打开一次“中英本地校对”，等待准备完成。

已有版本可通过“检查更新”升级到 1.3.0；旧更新器会先升级三个核心组件，完成后再检查一次安装校对组件。同签名覆盖保留词库和设置，请勿卸载或清除键盘数据。

```powershell
./install.ps1 -Serial YOUR_ADB_SERIAL -ApkDirectory ./downloads
```

会安装并选中“Gboard 中文本地增强”，原版 Gboard 保留。语音首次使用需麦克风授权。首次部署中文模型需要等待，安装包及部署后的模型占用较大。

恢复原版：系统“当前输入法”选择“Gboard”，或执行 `./restore-original.ps1 -Serial YOUR_ADB_SERIAL`。恢复不删除学习数据。

讯飞的断网是手机系统网络策略配置，不由本 APK 执行。本次真机已禁止讯飞移动数据与 WLAN，并停止讯飞、关闭其输入法入口。更换手机或重新做讯飞对比测试前，需先建立同样的网络隔离。

## 验证与限制

12 个古文固定短语的完整拼音，原版精确首候选为 7/12；不读取测试快捷码的本地引擎为 10/12。18 个现代词语/短语例子为 18/18。这是小样本功能检查，不能当作整体准确率或讯飞对比结论，没有整段古文默写。

1.0.0 真机验证了未确认拼音内部编辑、英文候选、隐私界面、离线语音回填。1.1.0 AVD 验证了实际中文适配器的回车提交、关闭联想与文字选择、原生候选控件向下和向上翻页，以及双语音频识别、录音接口开始/结束/取消。双语样本来自模型的公开测试音频，普通话样本为本机合成，未采集真人语音准确率样本。

ARM Gboard 原生解码器在 x86 AVD 翻译环境有上游崩溃；候选控件在独立调试 Activity 中运行，因此上述结果不代表完整键盘界面、英文解码器或物理震动在 AVD 的测试通过。1.1.0 未重新进行真机测试。

1.1.1 AVD 使用实际候选控件验证组成拼音时隐藏 ×、提交后显示 ×、原生展开按钮保留、触摸区域不重叠，以及重新输入后释放 × 占用的宽度。测试 IME 在真实输入法窗口中运行正式源码的 VoiceHook，以合成普通话音频验证立即启动、结果直接提交及面板自动关闭；同时测试识别到语音停顿后自动结束。测试 IME 和音频入口仅用于 AVD，均不在正式发布 APK 内。

AVD 还通过应用内检查从公开 GitHub 下载并更新全部组件。安装后的六个 APK 与发布文件 SHA-256 一致，安装来源为更新应用；重新打开应用显示更新成功，再次检查提示“已是最新版本”。正式语音包通过同签名测试 instrumentation 在键盘 UID 下验证录音开始/结束/取消，并拒绝调试音频入口。测试 APK 不在正式发布文件中。

1.2.0 AVD 验证了实际 Rime 光标编辑、逐字符触感调用次数、点按放大、空格微调、松手不误确认、原生 SoftKeyboardView 分发钩子、中文普通点按及英文手势放行。实际 Zinnia 模型识别了合成笔画“一、二、人、木、中”，验证选词、逐笔撤销和独立手写板退出；这些样例不代表手写准确率。手写模型随安装包附带，无需下载，当前一次识别一个简体汉字，笔顺和写法会影响候选排序。

独立测试 IME 还验证了拼音放大框在真实输入法窗口中显示，且输入连接保持有效。1.2.0 从旧更新器实际安装后，六个 APK 哈希、17 个本地 Rime 用户文件及设置均保留。1.2.1 修正系统返回结果时页面刷新不及时，并以实际私有 receiver 和打开的更新页面验证系统拒绝、取消两种状态，无需重新打开页面。

1.2.2 进一步验证独立手写板保留原生删除键的显示和触摸，能够逐笔撤销；原生解码器正在组成的拼音不会被手写手势清掉。候选控件翻页回归首次在 500 毫秒观察窗口内未翻页，重新启动测试进程后通过，记录保留在该版适配器报告中；本补丁没有修改翻页源码。

1.2.2 在 AVD 从公开 GitHub 下载并完成升级后，还实际执行了一次“重新安装此版本”。两次安装的六个 APK 均与发布文件一致；修复安装后键盘安装更新时间变化、首次安装时间不变，18 个本地 Rime 用户文件与设置均保留。管理入口、成功提示、实际组件版本及重复检查的最新版本提示均已验证。

中文排序与讯飞不同，不能保证逐项一致。简拼命中仍有局限；物理震动延迟未测量，系统或硬件可能合并连续的触感请求。原版的私有英文学习历史没有迁移。双语语音仍可能出现识别错误，不保证方言或自动标点。增强版通过本项目更新，Gboard 底包升级需重新适配。

1.2.3 本地构建在 AVD 以原生 SoftKeyView 和候选布局验证独立字号、主题和高度变化、重复测量、候选复用、控件池宽度计算、上下限及设置保存；候选展开、关闭和翻页回归通过。ARM64 真机已从 1.1.1 同签名覆盖升级，六个实际安装 APK 的 SHA-256 与本地正式包一致，首次安装时间保持不变；真机点按两组字号加减按钮并核对显示值后恢复键盘 100%、候选 115%。未重新进行完整真机输入或语音回归。

1.2.4 在 AVD 合成编辑框验证 C/V/B/N 三个下缘位置、正常空格确认、拼音光标及手写回归；离线合成语音验证普通填入、录音期间输入连接刷新、首次提交失败保留结果及点击重试。测试源码哈希与最终源码清单一致。ARM64 真机已同签名覆盖升级到 1.2.4，全部六个安装 APK 哈希、版本号、首次安装时间与默认输入法已核验；没有在个人聊天应用进行真人语音测试。

1.2.5 先在真机自建隐私编辑框复现 1.2.4 的 N 变 J，然后安装正式键盘验证 C/V/B/N 的上半部、中心、下缘、行间和空格上沿共 20 个位置；空格确认、连续 cvbn、移动拼音光标后插入字母及横线手写选中“一”通过。候选 150% 的 xiang 以及 125% 的五格手写候选截图经目视检查没有重叠，测试后恢复原键盘 110%、候选 125%。六个已安装 APK 哈希、版本、首次安装时间和默认输入法已核验。没有在个人聊天应用发送测试按键，未重跑语音测试。

详见 [构建说明](docs/BUILD.md)、[隐私设计](docs/PRIVACY.md)、[第三方来源](docs/THIRD_PARTY.md) 和 [测试结果](tests/results)。`release-manifest.json` 给出全部 APK 的 SHA-256，`source-manifest.json` 记录 Java/JNI 源文件哈希。

1.2.6 在真机确认旧服务麦克风 `silenced:true`，新输入法采集为 `silenced:false`。正式键盘和正式语音服务通过手机扬声器播放的合成普通话测试句，完成真实麦克风采集、离线识别和输入框填入；自动结束与手动结束均有检查。这是合成音频声学回放测试，未测真人语音整体准确率。AVD 还验证匿名音频管道 EOF、模型载入期间停止不截断，以及输入连接刷新、提交失败重试。真机开启连写后，两次横画分别填入“一一”，测试后恢复独立手写板、连写开关与字号原设置。手写通过起笔曲线、底排坐标、长笔画尾部、逐笔渐淡、旧字仍可见时继续书写、取消待提交字等检查；没有更换模型，不宣称整体手写准确率已达到某个百分比。


1.3.0 的校对测试使用固定合成句，不是整体准确率评测。中文 NPU 与 CPU 均能修正“图书管、完城、记路”；数字、否定、编号和测试人名保留。部分歧义错误（包括测试中的 phone/want）会保留原文，不保证理解并修复所有语义问题。量化、体积、加速限制与来源见 [校对说明](enhanced/PROOFREADING-SOURCES.md)。未测量真实电池能耗，不把加速倍数当作省电百分比。

1.3.0 在真机正式包核验三种候选按钮模式及真实展开面板；语音模型通过系统语音接口预载后再开启麦克风。语音填入与句末标点已观察到，但声学回放受到周围人声干扰，本轮未确认固定句识别准确率。AVD 验证最终标点、自动填入、输入连接刷新、失败重试与恢复原文保护。
