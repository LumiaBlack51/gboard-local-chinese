# Gboard 中文本地增强

基于个人手机上的 Gboard 18.4.1 构建的非官方适配：保留原生键盘前端与英文解码器，用本地 Rime、雾凇词库、万象语法模型增强中文，并通过独立 Vosk 服务提供离线普通话语音。

代码位于本仓库，正式安装包位于 [v1.0.0 Release](https://github.com/LumiaBlack51/gboard-local-chinese/releases/tag/v1.0.0)。仓库为私有；APK 包含原 Gboard 闭源代码，新增源码不改变第三方代码及数据的许可。签名私钥不在仓库或 Release 中。

## 已实现

- 中文全拼、简拼、组合成句、词语补全、后续候选和本地选词学习；补全索引包含 874,429 条记录。
- 确认前点按或拖动拼音行中的 `│` 光标，插入字母或退格，实时更新候选。
- 保留 Gboard 触控与震动路径、原生英文预测和隐私键盘界面。
- 隐私或密码输入使用禁用用户词库的中文方案，不写选词学习，关闭麦克风。
- 点击麦克风 → 开始 → 完成或取消；Vosk 普通话识别只处理内存音频，使用显式本地服务，没有云识别回退。

增强版和语音服务均没有 `android.permission.INTERNET`，关闭系统备份。语音服务对调用方核验签名。没有读取讯飞学习数据库，没有调用讯飞代码或服务。

## 安装

下载 Release 的 **全部五个 APK**：`base.apk`、三个 `split_*.apk`、`voice-helper.apk`，放到同一目录。键盘 split 必须一起安装；ARM64、Android 12L 或更高。已在 Android 16 ARM64 真机验证，其他机型尚未验证。

```powershell
./install.ps1 -Serial YOUR_ADB_SERIAL -ApkDirectory ./downloads
```

会安装并选中“Gboard 中文本地增强”，原版 Gboard 保留。语音首次使用需麦克风授权。首次部署中文模型需要等待，安装包及部署后的模型占用较大。

恢复原版：系统“当前输入法”选择“Gboard”，或执行 `./restore-original.ps1 -Serial YOUR_ADB_SERIAL`。恢复不删除学习数据。

讯飞的断网是手机系统网络策略配置，不由本 APK 执行。本次真机已禁止讯飞移动数据与 WLAN，并停止讯飞、关闭其输入法入口。更换手机或重新做讯飞对比测试前，需先建立同样的网络隔离。

## 验证与限制

12 个古文固定短语的完整拼音，原版精确首候选为 7/12；不读取测试快捷码的本地引擎为 10/12。18 个现代词语/短语例子为 18/18。这是小样本功能检查，不能当作整体准确率或讯飞对比结论，没有整段古文默写。

真机验证了未确认拼音内部编辑、英文候选、隐私界面、离线语音回填。AVD 验证了本地学习与隐私不写学习数据，以及语音录音接口的开始、结束、取消。语音识别使用本机生成的公开测试音频，未采集真人语音准确率样本。

中文排序与讯飞不同，不能保证逐项一致。简拼命中仍有局限；物理震动延迟未测量。原版的私有英文学习历史没有迁移。当前语音不保证方言、自动标点或英文听写效果。增强版不会随原版商店更新，底包升级需重新适配。
