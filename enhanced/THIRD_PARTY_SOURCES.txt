Original interface and English engine: the user's installed Google Gboard 18.4.1.985164140-release-arm64-v8a, versionCode 176027078.
Local adapter and JNI sources: enhanced/src, enhanced/native/bridge.cpp, enhanced/native/voice.cpp, enhanced/native/handwriting.cpp.
Rime runtime 1.16.1: https://github.com/rime/librime
ARM64 runtime libraries extracted from official Fcitx5 Android 0.1.3-0-g048f581c package: https://github.com/fcitx5-android/fcitx5-android
Chinese dictionary: https://github.com/iDvel/rime-ice (GPL-3.0, original LICENSE in assets/local-rime/LICENSE).
Grammar: wanxiang-lts-zh-hans.gram, release LTS, https://github.com/amzxyz/RIME-LMDG (original license included separately).
Completion index: locally generated from the included dictionary, GBI3 format; source hashes in assets/local-rime/source-hashes.json.
Speech engine: Sherpa-ONNX 1.13.8, https://github.com/k2-fsa/sherpa-onnx
Speech model: sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20-mobile; the separate speech APK contains SHERPA-LICENSE and VOICE-MODEL-LICENSE.md.
Handwriting engine: Zinnia, BSD, upstream commit 581faa8f6f15e4a7b21964be3a5ec36265c80e5b, https://github.com/taku910/zinnia
Simplified Chinese handwriting model: Tegaki 0.3, LGPL 2.1, https://github.com/tegaki/tegaki/releases/tag/v0.3
Handwriting licenses and the complete editable model source link are bundled in assets/licenses/HANDWRITING-SOURCES.md.
Android RecognitionService attribution implementation checked against https://github.com/aosp-mirror/platform_frameworks_base/blob/master/core/java/android/speech/RecognitionService.java
Source and signed APKs are published at https://github.com/LumiaBlack51/gboard-local-chinese ; private input data and signing material are excluded.

Punctuation model: Sherpa-ONNX int8 CT-Transformer zh-en vocab272727, 2024-04-12; Alibaba ModelScope upstream (Apache-2.0). See PUNCTUATION-SOURCES.md and PUNCTUATION-LICENSE.
