## 1.3.5 可选词库共享

键盘与离线语音仍没有 INTERNET 权限。用户启用共享后，独立更新应用通过签名保护的 provider，仅获取规范化中文词语、拼音、导入权重及累计选择次数和每词最近选择时间，并将其发送至用户配对的 HTTPS 服务。该应用不获取输入连接、逐键事件、密码、音频或模型。词条本身可能含个人姓名等信息，仅在用户设备和自有服务器私有目录保存，不进入公开仓库或 Release。共享为并集合并，清除本地词库不会自动清除云端。运行时和调度详见 [词库共享说明](DICTIONARY-SYNC.md)。以下旧版本说明中「更新器不读取词库」描述的是启用共享之前的行为。

# 隐私设计

1.3.2 的导入词库仅来自用户在系统文件选择器明确选取的文件。解析不联网，不保留文件 URI 的长期权限，不读取讯飞私有目录。词条在键盘 UID 的 `no_backup/local-dictionary` 下原子保存，与 Rime 学习词库隔离；可单独清除。显式导入的词条可在隐私输入中匹配，选词仍不写 Rime 学习数据。导入失败不记录词条或文件内容到日志。详见[词库导入说明](DICTIONARY-IMPORT.md)。

中文和语音均使用安装包内的数据，在本机处理。两个正式 APK 不请求 INTERNET，应用备份关闭；Rime 学习数据在应用私有 `no_backup/local-rime/user`。

1.2.0 手写使用随包附带的 Zinnia/Tegaki 简体中文模型，不联网。笔画坐标只在内存中用于当前字，选词后丢弃；连写时仅为淡出动画保留旧字坐标约 1.4 秒，取消或切换编辑框后立即丢弃，不记录手写轨迹。

编辑框带 `IME_FLAG_NO_PERSONALIZED_LEARNING`，或为密码类型时，中文使用 `local_pinyin_private`，其 `enable_user_dict` 为 false。单独设置 Rime 的 incognito 选项不足以阻止学习，因此使用独立方案。测试确认该模式不改变普通学习词库。手工配置的 Android 系统词典与普通学习词库不同，其备份受手机系统设置管理。

语音通过指定 `local.gboard.voice/.OfflineRecognitionService` 使用本地 Sherpa-ONNX 双语模型；不调用系统默认识别服务。服务核验调用 UID 的签名，两个应用需要同一密钥签名。音频不保存，不写用户语音记录。结束、取消、键盘隐藏和编辑框变化均清理或丢弃会话结果。

调试版的合成音频入口仅接受拥有 DUMP 权限的调用，并限制到自建测试编辑框。正式版关闭 debuggable，不注册此入口；语音 APK 不包含合成测试音频。仓库包含诊断源码，以便复核，但没有手机截图、ADB 日志、设备序列号、词库数据库、密钥或访问令牌。

原 Gboard 为闭源软件，保留其前端和英文逻辑。这里的无网络权限检查和新增代码的本地处理验证，并不等于对全部原 Gboard 代码完成独立隐私审计。

1.1.0 新增 `local.gboard.updater`，独立 UID，仅用户点击检查或安装时连接 GitHub。它请求 INTERNET 和 REQUEST_INSTALL_PACKAGES，不请求麦克风、不提供输入法、不接收输入内容。管理界面核验配套更新应用签名；更新器核验发布清单的签名身份、大小及 SHA-256，并核验各组件主 APK 的包名、版本与证书。Android 安装器最终校验所有 split 签名，并在用户确认后原子提交三组件。取消或下载校验失败不会替换原版本；不自动后台检查。

1.2.0 更新器还核验实际安装的六个 APK 的大小及 SHA-256，只读取系统安装文件，不读取键盘词库、偏好或输入内容。同版本重新安装仍通过安卓安装确认并保留应用数据。

1.2.6 正式录音由当前输入法 UID 打开麦克风，避免独立后台语音服务被系统静音。16 kHz 单声道 PCM 经匿名内存管道送至同签名离线服务；模型载入/解码与录音分线程，最多缓存约 120 秒。停止会关闭麦克风并识别已采集音频；取消、隐藏或换输入框会关闭管道并丢弃结果。不保存录音，不上传音频或文字。

1.3.0 的 `local.gboard.proofread` 是同签名的独立文本校对组件，无 INTERNET、麦克风或备份权限。ONNX AAR 的默认 manifest 和遥测初始化器不合并，并禁用运行库遥测。只传当前语音文字，不传录音、历史或编辑框上下文；模型和编译缓存不含输入文本。取消、换编辑框、超时后丢弃结果。自动修改后的撤销仅在光标、选区和已提交后缀仍匹配时生效，不持久化原文。新版更新器将扩展组件纳入签名、哈希及安装文件校验，仍没有读取校对文本的接口。

语音快速启动仅预载模型，没有音频或编辑框文字；隐私／密码输入不触发预载，隐藏键盘后解除服务绑定。可在管理应用关闭。1.3.1 语音服务通过随包附带的 CT-Transformer 模型在本机恢复句中和句末标点，只处理当前识别文字，不保存文本或联网。逐字校验拒绝模型漏字、改字的结果。标点模型不可用时，键盘继续提供句末标点回退。
